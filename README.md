A web-based Faculty Feedback System developed using **PHP, MySQL, HTML, CSS, JavaScript**, and **XAMPP**. The system allows administrators to manage faculty, students, subjects, and collect structured feedback efficiently.

## Features
- Admin authentication with session management
- Add, manage, and delete faculty records
- Add and manage students with year-wise subject allocation
- Excel file upload for bulk student import
- Dynamic subject loading using AJAX
- Secure MySQL database integration

## Tech Stack
- Frontend: HTML, CSS, JavaScript, jQuery
- Backend: PHP
- Database: MySQL
- Server: XAMPP

## Installation Steps
1. Install **XAMPP**
2. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Faculty-Feedback-System-PHP-MySQL.git
   ```
3. Move the project to:
``` C:/xampp/htdocs/ ```
4. Import database.sql into phpMyAdmin
5. Update database credentials if required
6. Start Apache & MySQL
7. Open browser:
```
http://localhost/Faculty-Feedback-System-PHP-MySQL
```
